# ML-модуль: Сервис формирования цифрового признака ТС

Этот раздел репозитория отвечает за извлечение векторного представления (эмбеддинга) автомобиля по изображению и координатам BBox.

## Что реализовано

* **Модель:** Архитектура ResNet50, обученная с использованием функции потерь ArcFace. Это позволяет формировать устойчивые кластеры в латентном пространстве и корректно работать в условиях Open-set (идентифицировать автомобили, которых не было в обучающей выборке).
* **Режим отказа:** Оптимальный порог уверенности (0.36) вычислен математически. Мы проанализировали распределение косинусного расстояния на 4 млн пар и выбрали точку, максимизирующую F1-score.
* **API-ready модуль:** Процесс обрезки изображения и генерации вектора вынесен в изолированный класс `VehicleFeatureExtractor` для мгновенной интеграции с бэкендом.

## Структура файлов

* `core/` — продакшен-код для сборки микросервиса. Включает скрипт инференса и обученные веса (`weights/`). Эту папку использует бэкенд.
* `expeiments/` — исследовательская среда. Содержит скрипты парсинга BBox, тренировочный цикл и код расчета порога.
* `requirements.txt` — зафиксированные версии библиотек для сборки Docker-образа.
